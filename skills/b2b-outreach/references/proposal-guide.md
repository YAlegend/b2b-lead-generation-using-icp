# Proposal Guide — Phase 6

## Structure

1. **Executive Summary** (half page)
   - Their problem in their words
   - Your proposed solution in 3 bullets
   - Expected outcome / result

2. **Scope of Work**
   - Phase-by-phase breakdown
   - What's included / explicitly excluded
   - Key assumptions

3. **Deliverables**
   - Specific, tangible outputs
   - File formats / handover method

4. **Timeline**
   - Week-by-week milestones
   - Client responsibilities at each stage

5. **Investment**
   - Fixed price or T&M
   - Payment schedule (recommend: 30–50% upfront)
   - What's not included (change control)

6. **Next Steps**
   - Signature block
   - Deposit invoice trigger
   - Kick-off call date

## Pricing Guidance

- Price anchoring: present 3 options (Good / Better / Best)
- Never discount more than 10% without removing scope
- Always justify the price with reference to outcomes, not hours
- For deals over £20k: milestone-based payments (30% / 40% / 30%)

## Proposal Follow-Up Sequence

- Day 0: Send proposal
- Day 3: "Just checking you received this — happy to walk through it on a call"
- Day 7: "Any questions on the proposal? Also happy to adjust scope if needed"
- Day 14: "Is this still a priority for [month]? If timing has shifted I'm happy to revisit"
